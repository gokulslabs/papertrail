# Privytrail

A private document library that runs in the browser. Receipts, bills, warranties and other files stay in IndexedDB on this device. There is no account and nothing is uploaded.

This app is a Privytrail build inspired by [papertrail.abhinavjha.site](https://papertrail.abhinavjha.site/).

## Development

```sh
bun install
bun run dev
```

## Scripts

- `bun run dev` — local site
- `bun run test` — unit tests
- `bun run build` — production build
